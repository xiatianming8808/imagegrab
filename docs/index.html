WHY IMAGEGRAB

详情页的图，本来就该一键拿到

做电商素材、做竞品分析、做详情页复刻，最耗时的从来不是设计，而是把图一张张存下来。

电商详情页的图片通常分散在三类位置：<img> 标签、懒加载的 data-src 属性，以及用 CSS 背景图拼出来的“无缝长图”。右键另存只能拿到第一屏， 往下滚动再存，又会重复、会漏。

图提取的思路很直接：在页面里跑一遍扫描，把这三类地址全部收集起来，按真实像素尺寸过滤掉图标、 logo、占位图与 1×1 埋点，剩下的去重后放进一个网格页面。你在网格里勾选，插件负责转成 PNG、 按顺序命名、逐个下载。

整个过程不经过任何服务器——图片从你的浏览器直接进你的下载目录，不登录、不上传、不埋点。

图片分散

主图、细节图、长图、背景图分别在不同标签与属性里，逐个右键太慢。

无法批量保存

浏览器没有“把这一页的图都存下来”的入口，装下载器又常常夹带广告。

格式不统一

webp、jpeg、png 混在一起，提交素材或再编辑时还要逐个转格式。

FEATURES

六个功能，覆盖从抓取到落盘

没有多余开关，装上就能用。

01

一键提取

自动扫描页面所有商品图，兼容懒加载（data-src / srcset）与 CSS 背景图，滚动到底也不漏。

02

智能过滤

按真实像素尺寸与路径关键词排除 favicon、icon、logo、sprite、占位图与 1×1 埋点，支持自定义排除词。

03

集中预览

结果在新标签页以网格展示，每张显示尺寸与序号，加载失败的图会单独标出来，不会静默吞掉。

04

自由勾选

全选、反选、仅选大图、清空，也可以单张点选；快捷键 Ctrl+A 全选、Esc 清空。

05

统一 PNG

下载前统一转码为 PNG，跨域图片转码失败时自动回退保存原始文件，并标注 raw- 前缀。

06

批量下载

一键保存到 下载/imagegrab/域名/，文件名从 01.png 顺序编号，重名自动加后缀。

INSTALL

四步装好，不用商店审核

属于“开发者模式加载”，适合自己用、也适合团队内部分发。

  1. 1

    下载插件压缩包并解压

    把压缩包解压到本地一个固定文件夹，例如 D:\extensions\imagegrab。这个文件夹以后不能删。

  2. 2

    打开扩展管理页

    Chrome 地址栏输入 chrome://extensions 回车。

  3. 3

    打开开发者模式

    页面右上角把「开发者模式」开关打开，顶部会出现三个按钮。

  4. 4

    加载已解压的扩展程序

    点「加载已解压的扩展程序」，选中第 1 步那个文件夹（里面直接有 manifest.json），完成。
